## 📖 Tentang Resource Pack

Repository ini berfungsi sebagai *hosting* resmi sekaligus arsip pengembangan aset visual untuk plugin **Magplant**. Resource pack ini memuat tekstur dan model 3D kustom (`CustomModelData`) yang diperlukan agar item **Magplant** dan **Magplant Remote** tampil sesuai di dalam game.

### ✨ Fitur Utama
* **Kompatibilitas Penuh 1.20.1:** Menggunakan standar `pack_format: 15` tanpa peringatan *outdated pack*.
* **Ringan & Optimal:** Ukuran file kecil sehingga cepat diunduh pemain saat *join* ke server.
* **Siap Pakai untuk Server:** Mendukung distribusi otomatis melalui konfigurasi `server.properties` maupun plugin resource pack manager.
